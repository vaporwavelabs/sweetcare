# In-service bonus level prototypes

Standalone three.js (r160) prototypes for "In-service" training levels played before each ward theme.
Not wired into the game yet. Build the playable page with `python3 build.py` (inlines the sprite assets from
`assets.json` into `index.html`; run it from this folder after editing `src.html`). Open `index.html#fire`,
`#hands`, `#cpr` or `#sort` to jump straight into one.

- Fire Drill: P.A.S.S. (first-person extinguisher)
- Scrub Squad (WHO hand-hygiene steps, 20 s)
- Keep the Beat (CPR 100-120/min, 30:2)
- Safe Sort (sharps / biohazard / general conveyor)
